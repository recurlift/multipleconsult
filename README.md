# Multiple Consult, static site

Generated by `generate.py` (Python 3, no dependencies): `index.html`, `creators.html`, eleven use-case pages, shared `style.css`. Edit the data or templates in `generate.py` and run it. The existing Netlify `multipleconsult` project deploys `main` from this dedicated GitHub repository, with no build command and `.` as the publish directory. Photos: Pexels licence (free commercial use). Copy source: `RESEARCH/sales_app_bootcamp/SITE_COPY_SOL_2026_10_10.md`; cited study: Oldroyd, McElheran, Elkington, HBR March 2011.

## Local furniture intake experiment

`furniture-intake/index.html` is a self-contained styled prototype page with adjacent `model.js` and `app.js`. Open that file locally to review it. The route is `/furniture-intake/` when the full site folder is deployed. It uses synthetic samples and browser-local state only; it does not send form or photo data. This subdirectory is maintained separately from the pages generated by `generate.py`, so running the generator does not overwrite the experiment. Keep this route within the dedicated site repository; do not publish the subfolder as a separate Netlify project.
